# Kitopia — منصة أطفال (فيديوهات + قصص صوتية + ألعاب)

الواجهة بثلاث لغات: **العربية (RTL) · English · Türkçe**.

- **frontend/kids-frontend**: React 19 + Vite
- **backend/kids-backend**: Express 5 + MySQL + JWT
- **database/schema.sql**: هيكل قاعدة البيانات + الفئات العمرية والتصنيفات (بدون بيانات شخصية)

## المزايا
- فيديوهات يوتيوب تُعرض **داخل الموقع** (نافذة تشغيل مدمجة) دون أن يغادر الزائر.
- قصص صوتية، ولعبتان (فرقعة البالونات، ومسابقة الأرقام والألوان).
- **سجل المشاهدة والتوصيات**: يُسجَّل عمر الطفل عند التسجيل، فتُقترح فيديوهات فئته العمرية أولاً (وتُخفى فيديوهات الفئات الأخرى)، وتُقدَّم الفئات التي يشاهدها أكثر، ويُستثنى ما شاهده.
- لوحة تحكم للمدير: إضافة/حذف (مفرد ومتعدد) للفيديوهات والقصص والمستخدمين.
- متجاوب مع الهاتف والتابلت وسطح المكتب.

## التشغيل محلياً

1. أنشئ قاعدة بيانات فارغة `kids_platform` في MySQL (XAMPP → phpMyAdmin) ثم استورد `database/schema.sql`.
2. الباك اند:
   ```bash
   cd backend/kids-backend
   cp .env.example .env      # ثم غيّر JWT_SECRET إلى نص عشوائي طويل
   npm install
   npm run dev               # http://localhost:5000
   ```
3. الفرونت اند (يتصل بـ `http://localhost:5000` تلقائياً في التطوير):
   ```bash
   cd frontend/kids-frontend
   npm install
   npm run dev
   ```

## إنشاء حساب مدير

سجّل حساباً عادياً من الموقع، ثم اجعله مديراً:

```bash
cd backend/kids-backend
npm run make-admin -- your@email.com
```

## إضافة فيديو

لوحة التحكم ← **Videos** ← الصق رابط يوتيوب. فعّل **"Allow embedding / السماح بالتضمين"** للفيديو في YouTube Studio.

## النشر المجاني (خدمة واحدة + قاعدة بيانات)

السيرفر يخدم الواجهة المبنية والـ API معاً، فيكفي نشر خدمة واحدة:

1. **قاعدة البيانات**: أنشئ قاعدة MySQL مجانية على [TiDB Cloud](https://tidbcloud.com) (Starter)، ثم استورد `database/schema.sql`.
2. **الخدمة**: على [Render](https://render.com) اختر *New → Blueprint* واربط المستودع؛ يقرأ `render.yaml` تلقائياً، وتدخل قيم `DB_HOST` و`DB_PORT` و`DB_USER` و`DB_PASSWORD` و`DB_NAME` من TiDB.
3. سجّل حساباً من الموقع المنشور ثم اجعله مديراً (شغّل `npm run make-admin` محلياً بعد ضبط `.env` على قاعدة TiDB مع `DB_SSL=true`).

> ملاحظات الخطة المجانية: الخدمة تنام بعد 15 دقيقة بلا زيارات (أول طلب بعدها يستغرق نحو دقيقة)، والملفات المرفوعة (صوت/فيديو) تُمسح عند إعادة التشغيل — استخدم روابط يوتيوب للفيديوهات.
